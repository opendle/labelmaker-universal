## Description

Design and print labels from iPhone, iPad, or Mac.

Labelmaker gives you a direct WYSIWYG editor for labels and continuous tape.
Create a workspace with several labels, edit each label at its physical size,
and print one label or the complete workspace to a supported MakeID printer over
Bluetooth.

Features:

- Add and format text with typeface, size, weight, alignment, and rotation.
- Import images and adjust brightness, contrast, fit, and transparency.
- Draw monochrome artwork and add icons or basic shapes.
- Set label size, margins, printable area, and printer output settings.
- Create flag and cable-wrap labels with matching sides.
- Mirror printed output without changing the editor canvas.
- Save complete workspaces as local files and restore unfinished work.
- Work without an account, advertising, analytics, or cloud storage.
- Receive automatic updates through the App Store.

Labelmaker is open-source software under the GNU Affero General Public License
v3.0. You can build it from source at no charge. The small App Store price is an
optional way to support continued development and the printer hardware that is
needed to add and verify support for more models.

## App review notes

The app does not require an account. It uses Bluetooth only to find and print
to supported MakeID label printers. Reviewers can test all editor, file, and
workspace features without a printer. A physical printer is required only for
the final print operation.
