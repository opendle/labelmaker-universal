# Security policy

## Report a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub private
vulnerability reporting:

https://github.com/opendle/labelmaker-universal/security/advisories/new

Include the affected version or commit, operating system, reproduction steps,
and the expected impact. Remove printer addresses, labels, credentials, signing
material, and other private data from logs or captures.

## Current support status

The project is pre-release. No build has a stable security-support period yet.
The repository will publish a supported-version policy before its first public
binary release.
